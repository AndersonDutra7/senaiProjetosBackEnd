Guia da Prova — AutoVision

Passo a passo prático para construir o módulo de anúncios de veículos e registro de interesse exigido pelo enunciado, na ordem que gera mais pontos por minuto investido. O objetivo é sair do zero e chegar a uma aplicação funcional: banco → API → tela. Deixe estilo e detalhes visuais por último.

01

Setup do Projeto

~10 min

1. Extensões do VS Code para desenvolvimento offline

O autocomplete do Node.js (Express, pg, Multer) é nativo e funciona automaticamente offline assim que a pasta com a node_modules é aberta. Para agilizar a escrita de HTML, CSS e JavaScript sem internet, instale os arquivos .vsix das seguintes extensões:

2. Arquitetura do Projeto

Para uma prova offline de 3 horas, essa é a estrutura mais simples possível que ainda atende 100% do enunciado. Não adicione TypeScript, build tools, frameworks de frontend (React/Vue) ou ORMs (Prisma/Sequelize) — cada camada extra é tempo que você não tem. pg puro com queries SQL diretas é mais rápido de escrever e de debugar sob pressão.

3. Comandos iniciais (rodar em ordem)

Copie e cole no terminal, dentro da pasta do projeto. 

# inicializa o projeto
npm init -y

# dependências mínimas: servidor, banco, upload de imagem
npm install express pg multer

# pastas que o Express/multer vão precisar

Decisão que economiza tempo: não implemente login com sessão de servidor (express-session) nem hash de senha (bcrypt). Como o enunciado não exige recarregar a página, guarde o usuário logado em uma variável no app.js (memória do navegador) e envie o usuario_id junto de cada requisição que precisar dele (registrar interesse, cadastrar anúncio, ver perfil). Isso ainda atende 100% da especificação funcional e corta ~30 minutos de implementação.
02

Banco de Dados

~25 min

1. As três entidades do enunciado

O enunciado define exatamente 3 entidades: Usuários (clientes e vendedores, ambos fazem login), Anúncios (criados só por vendedores) e Interesses (clientes e vendedores podem registrar interesse em um veículo). Modele exatamente isso — não crie tabelas extras. 

-- schema.sql

-- 1. Usuários: clientes ou vendedores, todos fazem login
CREATE TABLE usuarios (
  id SERIAL PRIMARY KEY,
  nome VARCHAR(100) NOT NULL,
  usuario VARCHAR(50) UNIQUE NOT NULL,
  senha VARCHAR(100) NOT NULL,
  tipo VARCHAR(20) NOT NULL CHECK (tipo IN ('cliente', 'vendedor')),
  telefone VARCHAR(20),
  foto_perfil VARCHAR(255)
);

-- 2. Anúncios: só vendedores criam
CREATE TABLE anuncios (
  id SERIAL PRIMARY KEY,
  titulo VARCHAR(100) NOT NULL,
  local VARCHAR(100) NOT NULL,
  preco NUMERIC(10,2) NOT NULL,
  imagem VARCHAR(255) NOT NULL,
  vendedor_id INTEGER NOT NULL REFERENCES usuarios(id) ON DELETE CASCADE,
  criado_em TIMESTAMPTZ DEFAULT NOW()
);

-- 3. Interesses: clientes e vendedores podem registrar; máx. 1 por anúncio/usuário
CREATE TABLE interesses (
  id SERIAL PRIMARY KEY,
  anuncio_id INTEGER NOT NULL REFERENCES anuncios(id) ON DELETE CASCADE,
  usuario_id INTEGER NOT NULL REFERENCES usuarios(id) ON DELETE CASCADE,
  UNIQUE (anuncio_id, usuario_id)
);
Por que UNIQUE (anuncio_id, usuario_id)? Isso faz o próprio banco recusar um segundo registro de interesse do mesmo usuário no mesmo anúncio — você não precisa validar isso "na mão" no backend, só tratar o toggle (ou, melhor, checar antes com um SELECT, como no passo 03).

2. Rodando o schema no pgAdmin

Passo Ação
1 Abra o pgAdmin, crie um banco chamado autovision (clique direito em Databases → Create → Database).
2 Clique com o banco selecionado, abra a Query Tool.
3 Cole o conteúdo de schema.sql inteiro e execute (F5).
4 Confirme que as 3 tabelas aparecem em Schemas → public → Tables.

3. Importando o usuarios.csv do protótipo

O enunciado pede continuidade dos dados do protótipo. O jeito mais rápido offline é usar a ferramenta gráfica de importação do próprio pgAdmin — sem escrever código de import.

Passo Ação
1 Rode primeiro o CREATE TABLE usuarios do schema (a tabela precisa existir antes).
2 Clique direito na tabela usuarios → Import/Export Data...
3 Ative a chave "Import", selecione o arquivo usuarios.csv.
4 Na aba Options, marque Header se o CSV tiver cabeçalho, e confira o delimitador (geralmente , ou ;).
5 Na aba Columns, confirme se as colunas do CSV batem com as colunas da tabela; se os nomes forem diferentes, mapeie manualmente.
6 Clique em OK e depois confira com SELECT * FROM usuarios; na Query Tool.
Atenção: se o CSV não tiver a coluna tipo (cliente/vendedor), você vai precisar rodar um UPDATE usuarios SET tipo = 'vendedor' WHERE usuario IN (...) depois da importação para os vendedores citados no enunciado.

3. Rotas — vitrine, busca por vendedor e status de interesse 

app.get('/api/anuncios', async (req, res) => {
  const { vendedor, usuario_id } = req.query;
  const params = [];

  // Subquery no PostgreSQL para checar se o usuário logado já registrou interesse
  let interessouSubquery = 'FALSE AS interessou';
  if (usuario_id) {
    params.push(usuario_id);
    interessouSubquery = `EXISTS(
      SELECT 1 FROM interesses i 
      WHERE i.anuncio_id = a.id AND i.usuario_id = $${params.length}
    ) AS interessou`;
  }

  let query = `
    SELECT a.id, a.titulo, a.local, a.preco, a.imagem,
            u.nome AS vendedor, u.usuario AS vendedor_usuario, u.telefone AS vendedor_telefone,
            COUNT(i.id)::int AS interesses,
            ${interessouSubquery}
    FROM anuncios a
    JOIN usuarios u ON u.id = a.vendedor_id
    LEFT JOIN interesses i ON i.anuncio_id = a.id
  `;

  if (vendedor) {
    params.push(`%${vendedor}%`);
    query += ` WHERE u.usuario ILIKE $${params.length}`;
  }

  query += ' GROUP BY a.id, u.nome, u.usuario, u.telefone ORDER BY a.criado_em DESC';

  const { rows } = await pool.query(query, params);
  res.json(rows);
});
Essa rota faz duas coisas além de listar: (1) se usuario_id vier na query string, monta uma subquery EXISTS que retorna interessou: true/false para cada anúncio — é assim que o ícone de interesse já nasce marcado na tela para quem já registrou interesse; (2) os índices dos parâmetros ($1, $2...) são calculados dinamicamente com params.length, porque a ordem de usuario_id e vendedor no array muda dependendo de quais vierem preenchidos. Sem usuário logado, o app.js simplesmente não manda usuario_id e a subquery vira FALSE AS interessou.

4. Rota de login

app.post('/api/login', async (req, res) => {
  const { usuario, senha } = req.body;
  const { rows } = await pool.query(
    'SELECT id, nome, usuario, tipo, telefone, foto_perfil FROM usuarios WHERE usuario = $1 AND senha = $2',
    [usuario, senha]
  );
  if (rows.length === 0) {
    return res.status(401).json({ erro: 'Usuário não encontrado ou senha incorreta' });
  }
  res.json(rows[0]);
});

5. Registrar / remover interesse (toggle, máx. 1 por usuário) 

app.post('/api/interesses/:anuncioId', async (req, res) => {
  const { anuncioId } = req.params;
  const { usuario_id } = req.body;

  const existe = await pool.query(
    'SELECT id FROM interesses WHERE anuncio_id = $1 AND usuario_id = $2',
    [anuncioId, usuario_id]
  );

  if (existe.rows.length > 0) {
    await pool.query('DELETE FROM interesses WHERE id = $1', [existe.rows[0].id]);
  } else {
    await pool.query(
      'INSERT INTO interesses (anuncio_id, usuario_id) VALUES ($1, $2)',
      [anuncioId, usuario_id]
    );
  }

  const { rows } = await pool.query(
    'SELECT COUNT(*)::int AS total FROM interesses WHERE anuncio_id = $1', [anuncioId]
  );
  res.json({ interesses: rows[0].total, interessou: existe.rows.length === 0 });
});

6. Perfil do vendedor (menu lateral)

app.get('/api/perfil/:id', async (req, res) => {
  const { id } = req.params;
  const anuncios = await pool.query(`
    SELECT a.id, a.titulo, a.local, a.preco, a.imagem, COUNT(i.id)::int AS interesses
    FROM anuncios a LEFT JOIN interesses i ON i.anuncio_id = a.id
    WHERE a.vendedor_id = $1 GROUP BY a.id ORDER BY a.criado_em DESC
  `, [id]);

  const totalInteresses = anuncios.rows.reduce((acc, a) => acc + a.interesses, 0);

  res.json({
    totalAnuncios: anuncios.rows.length,
    totalInteresses,
    anuncios: anuncios.rows
  });
});

7. Cadastrar e excluir anúncio

app.post('/api/anuncios', upload.single('imagem'), async (req, res) => {
  const { titulo, local, preco, vendedor_id } = req.body;
  if (!req.file) return res.status(400).json({ erro: 'Imagem obrigatória' });

  const { rows } = await pool.query(
    'INSERT INTO anuncios (titulo, local, preco, imagem, vendedor_id) VALUES ($1, $2, $3, $4, $5) RETURNING *',
    [titulo, local, preco, req.file.filename, vendedor_id]
  );
  res.json(rows[0]);
});

app.delete('/api/anuncios/:id', async (req, res) => {
  await pool.query('DELETE FROM anuncios WHERE id = $1', [req.params.id]);
  res.json({ ok: true });
});

app.listen(3000, () => console.log('Servidor rodando em http://localhost:3000'));

1. Estado global e carregamento da vitrine

A vitrine aceita dois filtros opcionais na query string: vendedor (busca) e usuario_id (usuário logado, para o backend informar em quais anúncios ele já registrou interesse). O card de cada anúncio verifica a.interessou pra decidir se o ícone nasce marcado. 

let usuarioAtual = null; // guarda { id, nome, usuario, tipo, telefone, foto_perfil } após login

// --- 1. VITRINE DE ANÚNCIOS ---
async function carregarVitrine(filtroVendedor = '') {
  const params = new URLSearchParams();
  if (filtroVendedor) params.append('vendedor', filtroVendedor);
  if (usuarioAtual) params.append('usuario_id', usuarioAtual.id);

  const url = `/api/anuncios${params.toString() ? '?' + params.toString() : ''}`;
  const resp = await fetch(url);
  const anuncios = await resp.json();

  if (filtroVendedor && anuncios.length === 0) {
    document.getElementById('vitrine').innerHTML =
      '<p>Vendedor não encontrado</p>';
    return;
  }
  renderizarVitrine(anuncios);
}

function formatarPreco(valor) {
  return Number(valor).toLocaleString('pt-BR', { style: 'currency', currency: 'BRL' });
}

function renderizarVitrine(anuncios) {
  const vitrine = document.getElementById('vitrine');
  vitrine.innerHTML = anuncios
    .map((a) => {
      // Verifica se a API indicou que o usuário logado já registrou interesse
      const interessou =
        a.interessou ||
        (Array.isArray(a.usuarios_interessados) &&
          usuarioAtual &&
          a.usuarios_interessados.includes(usuarioAtual.id));
      const classeAtiva = interessou ? 'ativa' : '';

      return `
        <div class="anuncio-card">
          <img class="foto" src="/uploads/${a.imagem}" />
          <div class="tooltip">Anunciado por: @${a.vendedor_usuario}<br/>Local: ${a.local}</div>
          <div class="rodape-card">
            <span class="titulo">${a.titulo}</span>
            <div class="linha-preco">
              <span class="preco">${formatarPreco(a.preco)}</span>
              <span>
                <img class="interesse-icone ${classeAtiva}" data-id="${a.id}" src="assets/interesse.svg" />
                <span class="contador">${a.interesses}</span>
              </span>
            </div>
          </div>
        </div>
      `;
    })
    .join('');

  document.querySelectorAll('.interesse-icone').forEach((icone) => {
    icone.addEventListener('click', () => toggleInteresse(icone));
  });
}

// --- 2. INTERESSES ---
async function toggleInteresse(icone) {
  if (!usuarioAtual) {
    abrirModalLogin();
    return;
  }

  const anuncioId = icone.dataset.id;
  const resp = await fetch(`/api/interesses/${anuncioId}`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ usuario_id: usuarioAtual.id }),
  });
  const { interesses, interessou } = await resp.json();

  icone.classList.toggle('ativa', interessou);
  icone.closest('.linha-preco').querySelector('.contador').textContent = interesses;
}

6. Cadastro de anúncio (validação campo a campo)

Substitui o alert('Preencha todos os campos') único por validação individual, escrevendo a mensagem certa em cada span.msg-erro (erroTitulo, erroLocal, erroPreco, erroImagem), incluindo checagem de preço numérico e de extensão do arquivo. 

// --- 6. CADASTRO DE NOVO ANÚNCIO (Com validações individuais) ---
document
.getElementById('formCadastro')
.addEventListener('submit', async (e) => {
  e.preventDefault();

  const campoTitulo = document.getElementById('campoTitulo');
  const campoLocal = document.getElementById('campoLocal');
  const campoPreco = document.getElementById('campoPreco');
  const campoImagem = document.getElementById('campoImagem');

  const erroTitulo = document.getElementById('erroTitulo');
  const erroLocal = document.getElementById('erroLocal');
  const erroPreco = document.getElementById('erroPreco');
  const erroImagem = document.getElementById('erroImagem');

  // Limpa erros anteriores
  erroTitulo.textContent = '';
  erroLocal.textContent = '';
  erroPreco.textContent = '';
  erroImagem.textContent = '';

  let temErro = false;

  // Validação do Título
  if (!campoTitulo.value.trim()) {
    erroTitulo.textContent = 'O título do anúncio é obrigatório.';
    temErro = true;
  }

  // Validação da Localização
  if (!campoLocal.value.trim()) {
    erroLocal.textContent = 'A localização é obrigatória.';
    temErro = true;
  }

  // Validação do Preço
  const precoNumero = parseFloat(campoPreco.value);
  if (!campoPreco.value || isNaN(precoNumero) || precoNumero <= 0) {
    erroPreco.textContent = 'Informe um preço válido maior que zero.';
    temErro = true;
  }

  // Validação da Imagem
  const arquivo = campoImagem.files[0];
  if (!arquivo) {
    erroImagem.textContent = 'Nenhum arquivo escolhido.';
    temErro = true;
  } else {
    const extensoesValidas = ['jpg', 'jpeg', 'png', 'gif', 'webp'];
    const extensao = arquivo.name.split('.').pop().toLowerCase();
    if (!extensoesValidas.includes(extensao)) {
      erroImagem.textContent =
        'Formato inválido (use JPG, JPEG, PNG, GIF ou WEBP).';
      temErro = true;
    }
  }

  if (temErro) return;

  // Envio para a API
  const formData = new FormData();
  formData.append('titulo', campoTitulo.value.trim());
  formData.append('local', campoLocal.value.trim());
  formData.append('preco', precoNumero);
  formData.append('vendedor_id', usuarioAtual.id);
  formData.append('imagem', arquivo);

  const resp = await fetch('/api/anuncios', {
    method: 'POST',
    body: formData,
  });

  if (resp.ok) {
    e.target.reset();
    carregarVitrine();
    document.getElementById('btnVerPerfil').click(); // Recarrega os dados do perfil
  }
});
Note que o cadastro só chama e.target.reset() e recarrega a vitrine/perfil dentro do if (resp.ok) — se o backend recusar (ex.: erro no upload), o formulário permanece preenchido para o aluno tentar de novo, em vez de limpar silenciosamente.

2. Requisitos do enunciado fáceis de esquecer

  • Botão "Ver Perfil" desabilitado para usuário tipo cliente, habilitado só para vendedor.
  • Botão "Ver Perfil" fica desabilitado também para visitante não logado.
  • Interesse: máximo 1 por anúncio por usuário — trate no banco (UNIQUE) e reflita no ícone (cor muda para azul).

  • Mensagens de erro exatas: "Usuário não encontrado ou senha incorreta" e "Vendedor não encontrado".
  • Upload de imagem: valida extensão (JPG, JPEG, PNG, GIF, WEBP) e mostra o nome do arquivo escolhido no botão.
