  2. Gravação temporária dos dados das transações bancárias no armazenamento local do navegador via LocalStorage.

Em um sistema bancário, o levantamento de requisitos de armazenamento determinou que, caso ocorra uma falha elétrica durante a transferência de valores entre duas contas, nenhuma das contas pode sofrer alteração parcial.
Qual propriedade do modelo ACID para armazenamento de dados garante este comportamento de "tudo ou nada"?
  1. Isolamento, que impede que transações executadas concorrentemente interfiram nos resultados intermediários de outras.
  2. Atomicidade, que garante que todas as operações da transação sejam executadas com sucesso ou nenhuma seja efetuada.
  3. Consistência, que assegura que o banco de dados transite de um estado válido para outro estado igualmente válido.
  4. Durabilidade, que garante que os dados gravados permaneçam salvos mesmo em cenários de falhas físicas de energia.
Na etapa de modelagem conceitual de dados para um sistema de biblioteca, identificou-se a entidade LIVRO e suas características titulo, isbn e ano_publicacao.
No Diagrama de Entidade-Relacionamento (DER), como são classificados LIVRO e titulo, respectivamente?
  1. Atributo e Entidade, pois LIVRO representa uma propriedade da biblioteca e titulo guarda o conjunto principal de dados.
  2. Chave Estrangeira e Relacionamento, pois LIVRO estabelece a ligação entre tabelas e titulo define a restrição de dados.
  3. Entidade e Atributo, pois LIVRO representa o objeto do mundo real e titulo é uma de suas propriedades características.
  4. Processo e Requisito, pois LIVRO descreve o fluxo de trabalho do sistema e titulo define a regra de negócio aplicável.
Ao aplicar técnicas de modelagem de dados para um sistema acadêmico, observou-se que um ALUNO pode se matricular em várias TURMAS, e cada TURMA possui vários ALUNOS.
Qual é a cardinalidade desse relacionamento e como ele deve ser implementado no modelo lógico relacional?
  1. Relacionamento N:N, resolvido por uma tabela associativa contendo as chaves estrangeiras provenientes de ambas as entidades.
  2. Relacionamento 1:1, resolvido pela criação de uma única coluna descritiva contendo todos os dados na tabela do Aluno.
  3. Relacionamento 1:N, resolvido pela inclusão do identificador único do Aluno como chave primária na tabela da Turma.
  4. Relacionamento sem cardinalidade definida, dispensando o uso de chaves primárias e estrangeiras no banco de dados.

Na fase de levantamento de requisitos de um sistema web, foram documentadas duas declarações:
I. "O sistema deve permitir que o usuário recupere sua senha via e-mail."
II. "A página inicial deve ser carregada em menos de 1,5 segundo."
Como são classificados os requisitos I e II, respectivamente?
  1. Requisito Funcional e Requisito Não Funcional, pois o primeiro descreve uma funcionalidade e o segundo um atributo de qualidade.
  2. Requisito de Hardware e Requisito de Banco de Dados, pois o primeiro exige servidores de e-mail e o segundo tabelas de banco.
  3. Requisito Não Funcional e Regra de Layout, pois o primeiro trata de segurança da conta e o segundo do visual da tela.
  4. Atributo de Qualidade e Caso de Uso, pois o primeiro define a velocidade da aplicação e o segundo a ação do usuário.

Qual heurística de usabilidade de Nielsen está sendo violada nessa especificação?
  1. Visibilidade do status do sistema, pois o sistema deve sempre manter o usuário informado sobre o que está acontecendo.
  2. Prevenção de erros, pois o sistema não exibe caixas de diálogo de confirmação antes de executar ações irreversíveis.
  3. Flexibilidade e eficiência de uso, pois a plataforma não disponibiliza atalhos avançados para usuários experientes.
  4. Design minimalista e estético, pois a tela apresenta excesso de elementos gráficos desnecessários durante a busca.
