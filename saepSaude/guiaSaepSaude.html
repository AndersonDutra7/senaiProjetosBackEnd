Guia de Referência — Full Stack

Material de apoio para a prova offline. Cobre do front-end (HTML, CSS, JavaScript) ao back-end (Node.js, Express) até a persistência de dados (PostgreSQL), na ordem em que essas camadas se conectam numa aplicação real.

01

HTML & CSS

camada de apresentação

1. Estrutura Base (o "Boilerplate")

O esqueleto padrão que todo documento HTML precisa ter. É o ponto de partida de qualquer página.

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Minha Página</title>
</head>
<body>
  <!-- conteúdo visível vai aqui -->
</body>
</html>
Tag / AtributoPara que serve
<!DOCTYPE html>Diz ao navegador que o documento é HTML5
<html>Elemento raiz, envolve tudo
<head>Metadados — não aparece na tela
<body>Conteúdo visível da página
meta charset="UTF-8"Garante acentuação e caracteres especiais corretos (ç, ã, é...)
meta name="viewport"Faz a página se adaptar a telas de celular (responsividade)
<title>Nome que aparece na aba do navegador

2. Textos e Hierarquia

Tags que dão estrutura e ênfase ao texto.

<h1>Título principal da página</h1>
<h2>Subtítulo de seção</h2>
<h3>Subtítulo menor</h3>

<p>
  Este é um parágrafo com uma palavra em <strong>negrito</strong>
  e outra em <em>itálico</em>.<br>
  Esta linha aparece logo abaixo, por causa do <br>.
</p>
📌
Regra do <h1>: use apenas um <h1> por página — ele representa o título principal do documento. Os demais níveis (h2 a h6) organizam o conteúdo em subseções, sempre em ordem decrescente de importância, sem pular níveis arbitrariamente.
TagSignificado
<h1>…<h6>Títulos, do mais (h1) ao menos (h6) importante
<p>Parágrafo de texto
<strong>Destaque de importância (visualmente negrito)
<em>Ênfase (visualmente itálico)
<br>Quebra de linha simples, sem abrir novo parágrafo

3. Links e Mídias

Como conectar páginas entre si e inserir conteúdo externo (imagens, vídeo, áudio).

<!-- link relativo: aponta para um arquivo dentro do próprio projeto -->
<a href="contato.html">Fale conosco</a>

<!-- link absoluto: aponta para outro domínio -->
<a href="https://exemplo.com" target="_blank" rel="noopener">
  Visitar site externo
</a>
AtributoPara que serve
hrefDestino do link — caminho relativo (/sobre.html) ou absoluto (https://...)
target="_blank"Abre o link em uma nova aba
rel="noopener"Boa prática de segurança ao usar target="_blank"
<img src="logo.png" alt="Logo da empresa">
AtributoPara que serve
srcCaminho do arquivo de imagem
altTexto alternativo — lido por leitores de tela e exibido se a imagem não carregar

Outras mídias comuns:

<!-- vídeo com controles de play/pause -->
<video src="aula.mp4" controls width="480"></video>

<!-- áudio -->
<audio src="musica.mp3" controls></audio>

<!-- iframe: incorpora outra página/documento dentro da atual -->
<iframe src="https://exemplo.com/mapa" width="600" height="400"></iframe>
TagUso
<video>Reproduz vídeo; controls exibe a barra de play/pause/volume
<audio>Reproduz áudio; mesma lógica do controls
<iframe>Incorpora outra página HTML dentro da atual (ex: mapa, vídeo do YouTube)

4. Agrupamento e Semântica de Layout

Containers neutros vs. tags que descrevem o papel do conteúdo.

<!-- div: bloco genérico, sem significado próprio -->
<div class="card">...</div>

<!-- span: em linha, sem significado próprio -->
<p>Preço: <span class="preco">R$ 49,90</span></p>

Já as tags semânticas comunicam a função do bloco — importante para leitores de tela e para deixar a estrutura do documento organizada:

TagPapel
<div>Container em bloco (quebra linha e ocupa toda a largura disponível). Usado para estruturar blocos de layout.
<span>Container em linha (não quebra linha, ocupa só a largura do texto). Usado para destacar ou estilizar trechos específicos.
<header>Cabeçalho da página ou de uma seção
<nav>Bloco de links de navegação
<main>Conteúdo principal da página (único por página)
<section>Agrupamento temático de conteúdo
<article>Conteúdo independente e reutilizável (post, card, notícia)
<footer>Rodapé da página ou de uma seção

5. Listas

Duas formas de agrupar itens: quando a ordem não importa, e quando importa.

<!-- não ordenada: menus, itens sem sequência -->
<ul>
  <li>Início</li>
  <li>Produtos</li>
  <li>Contato</li>
</ul>

<!-- ordenada: passo a passo, ranking, sequência numérica -->
<ol>
  <li>Criar o projeto</li>
  <li>Instalar as dependências</li>
  <li>Rodar o servidor</li>
</ol>
TagQuando usar
<ul>Lista não ordenada — menus de navegação, conjuntos sem sequência
<ol>Lista ordenada — passos, rankings, qualquer sequência numérica
<li>Cada item da lista, dentro de <ul> ou <ol>

6. Formulários (tópico vital para Node/Express)

É como o usuário envia dados para o servidor. Fundamental para entender as próximas camadas do stack.

<form action="/cadastro" method="POST">

  <label for="nome">Nome</label>
  <input type="text" id="nome" name="nome"
    placeholder="Digite seu nome" required>

  <label for="email">E-mail</label>
  <input type="email" id="email" name="email" required>

  <label for="idade">Idade</label>
  <input type="number" id="idade" name="idade" value="18">

  <label><input type="checkbox" name="aceite"> Aceito os termos</label>

  <label><input type="radio" name="plano" value="basico"> Básico</label>
  <label><input type="radio" name="plano" value="premium"> Premium</label>

  <label for="bio">Sobre você</label>
  <textarea id="bio" name="bio" placeholder="Conte um pouco sobre você"></textarea>

  <label for="cidade">Cidade</label>
  <select id="cidade" name="cidade">
    <option value="floripa">Florianópolis</option>
    <option value="sp">São Paulo</option>
  </select>

  <button type="submit">Cadastrar</button>

</form>
AtributoPara que serve
actionURL/rota para onde os dados do formulário são enviados
methodGET (dados na URL, para buscas) ou POST (dados no corpo da requisição, para criar/alterar)
for (no label)Deve ser igual ao id do input — clicar no label foca o campo
requiredImpede o envio se o campo estiver vazio
placeholderTexto de exemplo dentro do campo, some ao digitar
valueValor pré-preenchido do campo
⚠️
O atributo name é obrigatório: é ele — e não o id — que o navegador usa como chave ao enviar os dados. Sem name="..." no input, o Express não recebe aquele campo em req.body. O id serve só para ligar o <label> e para estilizar/selecionar via JS — ele não é enviado ao servidor.
ElementoUso
<textarea>Campo de texto de várias linhas
<select> / <option>Lista suspensa de opções
<button type="submit">Envia o formulário

CSS3 — Estilização e Layout

camada visual

1. Sintaxe Base e Formas de Inclusão

Anatomia de uma regra estilística e os métodos de vinculação ao documento HTML.

/* Sintaxe: Seletor { propriedade: valor; } */
h1 {
  color: #2b2b2b;
  font-size: 2rem;
}

/* Inclusão no HTML (<head>) */
<link rel="stylesheet" href="estilo.css">
MétodoSintaxe / ExemploDescrição e Uso Prático
<link> (Externo)<link rel="stylesheet" href="style.css">Padrão de mercado. Arquivo separado, reutilizável e armazenável em cache.
<style> (Interno)<style> body { background: #fff; } </style>Inserido no <head> do documento. Utilizado apenas para testes de prototipagem rápida.
Atributo style (Inline)<p style="color: red;">Inserido direto na tag. Evitar: possui especificidade altíssima e impede manutenção.
Regra @import@import url('estilos.css');Usado dentro de um arquivo CSS para puxar outro. Evitar em excesso (gera requisições em cadeia).

2. Seletores, Combinadores e Pseudoclasses

Mecanismos de alvejamento de elementos no DOM, hierarquia de especificidade e estados operacionais.

/* Combinadores e Seletores Compostos */
article > p { font-weight: bold; }      /* Filho direto */
input[type="text"] { border: 1px solid; } /* Atributo exato */

/* Pseudoclasses e Pseudoelementos */
.btn:hover { background: #0056b3; }
.card::before { content: "★ "; }
TipoSintaxeDescrição / Exemplo de Aplicação
Universal*Seleciona 100% dos elementos da página. Usado no reset de CSS.
Tagh1, p, buttonSeleciona por tipo de elemento HTML. Baixa especificidade (0,0,0,1).
Classe (.).btn, .card-titleSeleção reutilizável padrão. Especificidade média (0,0,1,0).
ID (#)#main-headerSeleciona elemento único. Alta especificidade (0,1,0,0). Deve ser usado com moderação.
Atributo[disabled], [type="submit"]Seleciona com base na presença ou valor de atributos HTML.
Filho Diretodiv > pAplica estilos apenas ao <p> que for filho imediato da <div>.
Descendentediv pAplica a qualquer <p> aninhado dentro da <div>, em qualquer nível.
Irmão Adjacenteh2 + pAplica ao <p> posicionado imediatamente após o <h2>.
Irmão Geralh2 ~ pAplica a todos os <p> irmãos que venham depois do <h2>.
:hovera:hoverEstado disparado quando o cursor do usuário passa sobre o elemento.
:focusinput:focusEstado de campo ativo (recebendo entrada do teclado ou clique).
:activebutton:activeEstado durante o momento exato do clique do mouse.
:disabled / :checkedinput:disabledPseudoclasses para formulários em estado desabilitado ou marcados.
:nth-child(n)li:nth-child(odd) | li:nth-child(2)Seleciona por posição matemática. Aceita números, odd (ímpar), even (par) ou 2n+1.
:not(seletor)button:not(.primary)Negação: aplica estilos a todos os elementos que NÃO correspondem ao seletor.
::before / ::after.box::before { content: ""; }Cria pseudo-elementos antes/depois do conteúdo da tag. Exige a propriedade content.

3. Box Model (Modelo de Caixa) e Dimensões

Cálculo de renderização espacial: todo elemento retangular é composto por Margem, Borda, Preenchimento e Conteúdo.

* {
  box-sizing: border-box; /* Essencial: width/height viram o tamanho final */
}

.container {
  width: 100%;
  max-width: 1200px;
  margin: 0 auto;        /* Centraliza container com largura definida */
  padding: 24px 16px;    /* 24px topo/base, 16px laterais */
  border: 1px solid #ddd;
}
📌
Sintaxes Abreviadas (Shorthands) de Padding e Margin:
• 1 valor (padding: 10px) = aplica em todos os 4 lados.
• 2 valores (margin: 10px 20px) = [1º: Topo/Base] [2º: Esquerda/Direita].
• 3 valores (margin: 10px 20px 30px) = [1º: Topo] [2º: Esquerda/Direita] [3º: Base].
• 4 valores (padding: 10px 20px 15px 5px) = Sentido horário: [Topo] [Direita] [Base] [Esquerda].
PropriedadeValores Mais UtilizadosComportamento Operacional
box-sizingborder-box | content-box (padrão)Com border-box, padding e border são absorvidos dentro da largura definida em width.
width / heightauto | px | % | rem | vw / vhDefine largura e altura fixas ou relativas do elemento.
min-width / max-width300px | 100% | 1200pxLimites dimensionais. Vital para responsividade em telas móveis.
padding8px | 16px 24px | 0 autoEspaçamento interno. Empurra o conteúdo para dentro, longe da borda.
margin16px | 0 auto (centraliza bloco) | -10pxEspaçamento externo. Empurra elementos vizinhos. Aceita valores negativos.
border1px solid #ccc | 2px dashed redShorthand para: [espessura] [estilo: solid|dashed|dotted|none] [cor].
border-radius4px | 8px | 50% (círculo perfeito)Arredondamento das quinas do elemento retangular.
outline2px solid blue | noneLinha externa à borda. Não ocupa espaço no Box Model. Utilizada no estado :focus.
overflowvisible | hidden | scroll | autoGerencia conteúdo que excede o tamanho do container (hidden corta, auto cria rolagem).

4. Layout Unidimensional — Flexbox

Sistema para alinhamento e distribuição de espaço de itens em uma única direção (linha ou coluna).

.flex-container {
  display: flex;
  flex-direction: row;
  flex-wrap: wrap;
  justify-content: space-between;
  align-items: center;
  gap: 16px;
}

.flex-item {
  flex: 1 1 200px; /* flex-grow | flex-shrink | flex-basis */
}

Propriedades do Container (Pai):

PropriedadeValores PossíveisDescrição Detalhada
displayflex | inline-flexAtiva o contexto Flexbox para todos os filhos diretos do elemento.
flex-directionrow | row-reverse | column | column-reverseDefine o eixo principal (Main Axis). row = horizontal (esquerda -> direita); column = vertical.
flex-wrapnowrap | wrap | wrap-reversenowrap (padrão) esmaga os itens em 1 linha; wrap permite quebra de linha quando não há espaço.
flex-flowrow wrap (exemplo de shorthand)Atalho para declaração conjunta de flex-direction e flex-wrap.
justify-contentflex-start | flex-end | center | space-between | space-around | space-evenlyAlinhamento ao longo do Eixo Principal.
• space-between: cola o primeiro e último item nas extremidades.
• space-around: espaço igual em volta de cada item.
• space-evenly: espaçamento perfeitamente idêntico entre todos os itens e as bordas.
align-itemsstretch | flex-start | flex-end | center | baselineAlinhamento ao longo do Eixo Cruzado (perpendicular ao principal).
• stretch: estica os itens para preencher a altura do container.
• baseline: alinha o texto interno de todos os elementos na mesma linha.
align-contentstretch | flex-start | flex-end | center | space-betweenAlinha as linhas inteiras quando há flex-wrap: wrap e múltiplos eixos com espaço sobressalente.
gap16px | 1rem | 10px 20pxDefine a distância mínima diretamente entre os itens flexíveis, eliminando a necessidade de margens manuais.

Propriedades dos Itens Filhos:

PropriedadeValores / FormatoDescrição e Uso
flex-growNúmero puro (ex: 0, 1, 2)Fator de expansão. 1 instrui o item a crescer para ocupar o espaço vago do container.
flex-shrinkNúmero puro (ex: 1, 0)Fator de encolhimento. 0 impede que o item seja esmagado se o container encolher.
flex-basisauto | 200px | 50%Tamanho base inicial do elemento antes da distribuição do espaço sobressalente via grow/shrink.
flexflex: 1 | flex: 0 0 250pxShorthand para flex-grow, flex-shrink e flex-basis. Sintaxe flex: 1 equivale a 1 1 0%.
align-selfauto | flex-start | flex-end | center | stretchSobrescreve a regra de align-items definida no pai apenas para este item específico.
orderInteiro positivo/negativo (ex: -1, 2)Altera a ordenação de renderização visual do elemento sem alterar o HTML. Padrão: 0.

5. Layout Bidimensional — CSS Grid

Sistema para construção de interfaces complexas baseadas em linhas e colunas simultâneas.

.grid-layout {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 20px;
}

.dashboard {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-rows: 60px 1fr 40px;
  grid-template-areas: 
    "header header"
    "sidebar main"
    "footer footer";
}
Propriedade / FunçãoValores e Exemplos PráticosDescrição Operacional
grid-template-columns200px 1fr 2fr | repeat(3, 1fr)Define a quantidade e largura das colunas. A unidade fr representa uma fração do espaço livre.
grid-template-rows80px auto 50px | repeat(2, 200px)Define a altura das linhas da grade.
grid-template-areasSintaxe por nomes em aspas (ver bloco de código acima)Mapeia a estrutura visual da página por nomes. Os itens filhos usam grid-area: nome para se posicionar.
repeat(n, valor)repeat(4, 1fr) | repeat(2, 100px)Função utilitária para repetir tamanhos de colunas/linhas sem redundância.
minmax(min, max)minmax(200px, 1fr)Garante que o elemento nunca seja menor que o mínimo nem maior que o máximo definido.
auto-fit / auto-fillrepeat(auto-fit, minmax(200px, 1fr))Cria colunas responsivas automáticas que se ajustam e quebram linha sem necessidade de Media Queries.
gap20px | row-gap: 10px; column-gap: 30px;Espaçamento entre células da grade.
justify-items / align-itemsstretch | center | start | endAlinha o conteúdo de todas as células nos eixos horizontal (justify) e vertical (align).
place-itemsplace-items: center;Shorthand para align-items + justify-items. Centraliza conteúdo dentro da célula.
grid-column (Item)1 / 3 | span 2 | 1 / -1 (da 1ª à última coluna)Define onde o item filho começa e termina nas colunas da grade (linha de início / linha de fim).
grid-row (Item)2 / 4 | span 3Define a ocupação vertical do item pelas linhas da grade.
grid-area (Item)header | 1 / 2 / 3 / 4Atribui o item a uma área nomeada em grid-template-areas ou shorthand para linhas/colunas.

6. Display, Posicionamento e Camadas

Controle sobre o fluxo de renderização, ordenação em eixos Z e posicionamento de elementos no espaço.

.modal-overlay {
  position: fixed;
  top: 0;
  left: 0;
  width: 100vw;
  height: 100vh;
  z-index: 9999;
}

.card-badge {
  position: absolute;
  top: 12px;
  right: 12px;
}

Modos de Exibição (Display):

Valor de displayComportamento no FluxoAceita Width/Height/Margin?
blockOcupa 100% da largura disponível. Força quebra de linha antes e depois. Ex: div, p, h1.Sim, aceita todas as propriedades.
inlineOcupa apenas o espaço exato do texto/conteúdo. Não quebra linha. Ex: span, strong, a.NÃO aceita width, height, ou margin vertical.
inline-blockPermanece em linha (sem quebrar linha), mas passa a respeitar dimensões e margens externas.Sim, aceita todas as propriedades. Ideal para botões.
flex / gridConverte o container em elemento bloco e ativa gerenciamento de filhos via Flexbox ou Grid.Sim.
noneRemove completamente o elemento da tela e da árvore de renderização (não ocupa espaço).Não se aplica.

Tipos de Posicionamento (Position):

ValorÂncora de ReferênciaComportamento / Uso Prático
static (padrão)Fluxo normal do documentoPosicionamento padrão. Ignora propriedades top, right, bottom, left e z-index.
relativeA sua própria posição originalDesloca o elemento a partir de sua vaga original sem tirá-lo do fluxo. Serve de âncora para filhos absolute.
absoluteAncestral mais próximo com position diferente de staticSai totalmente do fluxo. Posiciona-se com base no container pai relativo. Se não houver, usa o documento HTML.
fixedViewport (Janela do navegador)Sai do fluxo. Fica travado na tela mesmo ao rolar a página. Utilizado para modais, cookies e menus fixos.
stickyFluxo + limite de rolagem do containerHíbrido: comporta-se como relative até atingir um limite na rolagem (ex: top: 0), tornando-se "preso" (fixed).

Eixo Z e Visibilidade:

PropriedadeValoresEfeito Prático
z-indexInteiros (ex: -1, 0, 10, 9999)Controla a pilha de sobreposição no eixo Z. Só funciona em elementos com position diferente de static.
opacity0 a 1 (ex: 0.5)Define o nível de transparência do elemento e de todos os seus filhos.
visibilityvisible | hiddenCom hidden, o elemento fica invisível, mas DIFERENTE de display: none, ele continua ocupando espaço físico na tela.

7. Tipografia, Cores e Responsividade

Estilização de texto, manipulação de cores, unidades de medida e adaptação para dispositivos.

:root {
  --primary-color: #007bff;
  --bg-dark: #121212;
}

body {
  color: var(--primary-color);
  font-family: 'Inter', system-ui, sans-serif;
  font-size: 1rem;
}

/* Media Query para telas de até 768px (Smartphones/Tablets) */
@media (max-width: 768px) {
  .menu { flex-direction: column; }
}
CategoriaPropriedades / SintaxeDescrição e Boas Práticas
Tipografia Basefont-family, font-size, font-weightfont-weight varia de 100 a 900 (400 = normal, 700 = negrito). Usar fontes de sistema como fallback.
Formatação de Textoline-height, text-align, text-transform, text-decorationline-height: 1.5 garante boa legibilidade. text-transform: uppercase; text-decoration: none remove sublinhado de links.
Sistemas de Cores#Hex, rgb(), rgba(), hsl()rgba(0,0,0, 0.5) permite canal alfa para transparência. Hexadecimal de 6 dígitos (#ffffff) é a norma.
Variáveis CSS--minha-var: #fff; e var(--minha-var)Declaradas no escopo :root para reutilização centralizada de temas e paletas de cores.
Unidades AbsolutaspxTamanho fixo. Evitar uso em font-size por motivos de acessibilidade em leitores de tela.
Unidades Relativasrem, em, %1rem equivale ao tamanho padrão do elemento raiz HTML (geralmente 16px). em é relativo ao elemento pai.
Unidades de Viewportvw, vh, vmin, vmax100vw = 100% da largura da janela; 100vh = 100% da altura visível da janela.
Media Queries@media (max-width: 768px) { ... }Aplica blocos de código CSS apenas se as condições de tela forem atendidas (Mobile-First aborda min-width).

Cola rápida — CSS de Produção

  • Reset Essencial: Inicie todo projeto com * { box-sizing: border-box; margin: 0; padding: 0; }.
  • Centralização Suprema com Flex: display: flex; justify-content: center; align-items: center; no container.
  • Centralização Suprema com Grid: display: grid; place-items: center; no container.
  • Grade Automática Sem Media Query: grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));.
  • Âncora Absoluta: Para usar position: absolute em um filho, o pai PRECISA ter position: relative (ou outro que não seja static).
  • Centralizar Bloco Fixo: Elementos com width definido e display: block são centralizados na horizontal via margin: 0 auto;.
  • Formulários no Express: Inputs e Buttons necessitam da regra font-family: inherit; pois não herdam a fonte do body por padrão.
  • Evite ID no CSS: Estilize elementos com seletores de Classe (.). Deixe IDs reservados para navegação por âncora ou seletores JavaScript.

5. Tratamento Global de Erros

Captura centralizada de falhas ocorridas na aplicação utilizando o middleware especial de 4 parâmetros.

// Em qualquer rota, repasse exceções assíncronas chamando next(erro)
app.get("/erro", (req, res, next) => {
try {
  throw new Error("Falha ao conectar no banco");
} catch (erro) {
  next(erro); // Repassa o erro para o middleware global
}
});

// Middleware Global de Erros (DECLARAR POR ÚLTIMO, após todas as rotas)
app.use((err, req, res, next) => {
console.error(err.stack);
res.status(err.status || 500).json({
  erro: true,
  mensagem: err.message || "Erro interno no servidor"
});
});

Cola rápida — Express.js de Produção

  • Middleware de JSON em 1º Lugar: O app.use(express.json()) deve ser declarado ANTES das definições de qualquer rota.
  • A Regra do `return`: Ao responder dentro de um bloco condicional (ex: if), adicione `return res.status(...).json(...)` para evitar o erro "Cannot set headers after they are sent to the client".
  • Middleware de Erro Semper por Último: O middleware de 4 parâmetros `(err, req, res, next)` precisa ser a última linha da declaração do Express no arquivo.
  • Arquitetura Desacoplada: Separe a aplicação em Routes (endpoints), Controllers (lógica de requisição) e Services (regras de negócio).
  • Segurança Fundamental: Utilize bibliotecas essenciais como helmet (cabeçalhos HTTP de segurança) e cors (política de origem cruzada).
  • Rotas Inexistentes (404): Crie um middleware de fallback após as rotas para tratar endpoints não mapeados antes do middleware de erro.

4. Junções (JOINS) e Agrupamentos Agregados

6. Integração Node.js com o Driver pg (node-postgres)

Conexão via Connection Pool e execução segura de consultas parametrizadas contra SQL Injection.

const { Pool } = require("pg");

// Configuração do Connection Pool
const pool = new Pool({
  connectionString: process.env.DATABASE_URL,
  max: 20, // Máximo de conexões simultâneas reutilizáveis
  idleTimeoutMillis: 30000
});

// Consulta Parametrizada SEGURA (Proteção nativa contra SQL Injection)
async function buscarUsuario(email) {
  const query = "SELECT id, nome, email FROM usuarios WHERE email = $1";
  const { rows } = await pool.query(query, [email]); // $1 é substituído por [email]
  return rows[0];
}

Parâmetros $1, $2...pool.query('... WHERE id = $1', [id])Regra de Ouro: O driver limpa os dados antes de enviar ao banco. NUNCA concatene strings manuais no SQL.

rowCountconst { rowCount } = await pool.query()Número inteiro indicando quantas linhas foram afetadas pelo `INSERT`, `UPDATE` ou `DELETE`.

Cola rápida — PostgreSQL em Produção

  • Proteção Contra SQL Injection: JAMAIS faça `SELECT * FROM users WHERE name = '${req.body.name}'`. Use SEMPRE queries parametrizadas com placeholders $1, $2.
  • Prefira `JSONB` a `JSON`: O tipo JSONB consome uma fração de tempo a mais na escrita, mas é vertiginosamente mais rápido na leitura e aceita índices.
  • Fusos Horários Sem Dor de Cabeça: Utilize sempre o tipo TIMESTAMPTZ em vez de TIMESTAMP puro para salvar momentos exatos sem ambiguidade temporal.
  • Chaves Estrangeiras Indexadas: Sempre crie um INDEX manual sobre as colunas que são FOREIGN KEY para evitar travamentos de tabela em `JOINs` e `DELETEs`.
  • Nomes de Tabelas e Colunas: Prefira padrão em minúsculo e separado por underline (snake_case: ex: `criado_em`, `usuario_id`) para evitar ter que usar aspas duplas nas queries.
  • Diagnóstico de Lentidão: Se uma consulta estiver demorando, rode um EXPLAIN ANALYZE na query no DBeaver/pgAdmin para identificar se o banco está varrendo a tabela inteira (Seq Scan).
